Firmware for the Hermetic Modular Alchemy Lab V2

mi-alchemy

Mutable Instruments' Clouds, Elements, Marbles, Plaits and Warps, plus Meld, running on one 12HP panel. Put them all on the SD card and switch between them from the Lab's own firmware picker. The sound engines are Emilie Gillet's original code (and, for Warps and Meld, Matthias Puech's Parasites), unmodified apart from two marked fixes.

Status

Built and tested on a computer · not yet heard on hardware

Every firmware builds, and each engine passes its test suite running on a computer. None has been flashed to a module yet. Each manual lists what to check on the hardware.

Put them on the card

/alchemy/clouds_alchemy.bin
/alchemy/elements_alchemy.bin
/alchemy/marbles_alchemy.bin
/alchemy/plaits_alchemy.bin
/alchemy/warps_alchemy.bin
/alchemy/meld_alchemy.bin
/mi/elements.smp            Elements' exciter samples

Then hold B2 and B3 for two seconds to open Settings, turn to the firmware page, and pick one. Without /mi/elements.smp, Elements still plays, but its strike and blow samples are silent.

They share the card with Smack, Mark, Belt and Relay. Each firmware keeps its settings in its own preset slot, so switching doesn't lose them. Those four use slots 12–15, these use 6–11, and slots 0–5 are free for presets you save yourself.

What this version leaves out

  • The front USB-C is for the computer only (HostLink). There's no Launchpad support and no USB-audio mode yet.
  • Each manual lists the features of the original module that aren't here.

Found along the way

Clouds' time-stretch mode is silent when built from the current eurorack source, because a 2023 merge dropped one line. It's fixed here, and the fix was sent upstream as pichenettes/eurorack #72.
